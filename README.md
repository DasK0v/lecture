## Ответы к экзаменам

Ответы на экзаменационные вопросы, составленные по конспектам выше. Пока выложены
только исходники `.tex`, PDF не собраны.

| Предмет | Файл | Вопросы |
|---------|------|---------|
| Математический анализ, часть 1 | [tex](lec/matan_otvety_chast1.tex) | вопросы 1–23 (без 16): множества, функции, последовательности и их пределы, бесконечно малые и бесконечно большие, аксиома непрерывности, вложенные отрезки, подпоследовательности, грани множества, число $e$, предел функции по Коши и по Гейне, сравнение б.м.ф., эквивалентности, первый замечательный предел, непрерывность и точки разрыва |
| Линейная алгебра (курс аналитической геометрии) | [tex](lec/linal_otvety.tex) | вопросы 1–19: операции над матрицами, произведение матриц, определители и их свойства, обратная матрица, метод Гаусса, ступенчатая форма, ранг и критерий Кронекера–Капелли, однородные и неоднородные СЛАУ, собственные значения и векторы, симметрические и ортогональные матрицы, комплексные числа, формула Эйлера |

Как устроены файлы ответов:

- в начале каждого вопроса — план ответа;
- синие рамки — определения, зелёные — теоремы и свойства, доказательство идёт от △ до ▲;
- в матане пунктирная рамка — дополнение сверх лекций (учить, если останется время);
- в конце файла — сводная таблица определений: закрой правый столбец и проверяй себя;
- в начале файла перечислено, каких вопросов нет в лекциях и что пропущено
  (в матане — вопрос 16, в линале — первая часть вопроса 18).

В отличие от конспектов, файлы ответов не подключают `preamble.tex` — вся преамбула
внутри файла. Собираются pdfLaTeX, XeLaTeX или LuaLaTeX.

## Структура

```text
lec/
├── angem.tex      аналитическая геометрия (преамбула внутри файла)
├── matan.tex      математический анализ (преамбула внутри файла)
├── Proga.tex      программирование (преамбула внутри файла)
├── TF.tex         теоретическая информатика (преамбула внутри файла)
├── history.tex    история
├── preamble.tex   общая преамбула для history
├── matan_otvety_chast1.tex   ответы по матану, часть 1
├── linal_otvety.tex          ответы по линейной алгебре
├── *.pdf          собранные конспекты
└── build/         временные файлы сборки, в git не попадают
```

Один предмет — один файл. Новая лекция дописывается в конец файла своего предмета.

## Сборка

Нужен MiKTeX или TeX Live с `latexmk`. В MiKTeX нет Perl, без которого `latexmk`
не запускается, — его ставят отдельно, например [Strawberry Perl](https://strawberryperl.com/).
Компилятор — pdfLaTeX.

**VS Code.** Нужно расширение LaTeX Workshop (VS Code предложит его сам,
список лежит в `.vscode/extensions.json`). Настройки сборки уже в
`.vscode/settings.json`: файл собирается при сохранении или по `Ctrl+Alt+B`,
PDF появляется рядом с `.tex`, временные файлы уходят в `lec/build/`.

**Командная строка:**

```sh
cd lec
latexmk -pdf -aux-directory=build angem.tex
```

## Новый предмет

Создать `lec/<предмет>.tex` с такими первыми строками:

```latex
\documentclass[a4paper, 12pt]{article}
\input{preamble.tex}
```

Потом собрать, закоммитить `.tex` вместе с `.pdf` и добавить строку в таблицу выше.
