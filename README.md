# Конспекты лекций

Конспекты лекций в LaTeX. Готовые PDF лежат рядом с исходниками,
GitHub открывает их прямо в браузере.

- [`lec/`](lec) — конспекты лекций, один предмет — один файл;
- [`kollokvium/`](kollokvium) — ответы к коллоквиумам (там свой README со списком).

| Линейная алгебра (курс аналитической геометрии) | [PDF](kollokvium/linal_otvety.pdf)&nbsp;·&nbsp;[tex](kollokvium/linal_otvety.tex) | вопросы 1–19: операции над матрицами, произведение матриц, определители и их свойства, обратная матрица, метод Гаусса, ступенчатая форма, ранг и критерий Кронекера–Капелли, однородные и неоднородные СЛАУ, собственные значения и векторы, симметрические и ортогональные матрицы, комплексные числа, формула Эйлера |

Как устроены файлы ответов:

- в начале каждого вопроса — план ответа;
- синие рамки — определения, зелёные — теоремы и свойства, доказательство идёт от △ до ▲;
- в матане пунктирная рамка — дополнение сверх лекций (учить, если останется время);
- в конце файла — сводная таблица определений: закрой правый столбец и проверяй себя;
- в начале файла перечислено, каких вопросов нет в лекциях и что пропущено
  (в матане — вопрос 16, в линале — первая часть вопроса 18).

Файлы ответов не подключают `preamble.tex` — вся преамбула внутри файла.
Собираются pdfLaTeX, XeLaTeX или LuaLaTeX.

## Структура

```text
lec/                      конспекты лекций
├── angem.tex             аналитическая геометрия (преамбула внутри файла)
├── matan.tex             математический анализ (преамбула внутри файла)
├── proga.tex             программирование (преамбула внутри файла)
├── tf.tex                теоретическая информатика (преамбула внутри файла)
├── history_sdo.tex       история (СДО)
├── preamble.tex          общая преамбула для history_sdo
└── *.pdf                 собранные конспекты
kollokvium/               ответы к коллоквиумам
├── matan_otvety_chast1.tex   математический анализ, часть 1
├── linal_otvety.tex          линейная алгебра
└── *.pdf                     собранные ответы
```

Временные файлы сборки уходят в `build/` внутри каждой папки и в git не попадают.

Один предмет — один файл. Новая лекция дописывается в конец файла своего предмета.

## Сборка

Нужен MiKTeX или TeX Live с `latexmk`. В MiKTeX нет Perl, без которого `latexmk`
не запускается, — его ставят отдельно, например [Strawberry Perl](https://strawberryperl.com/).
Компилятор — pdfLaTeX.

**VS Code.** Нужно расширение LaTeX Workshop (VS Code предложит его сам,
список лежит в `.vscode/extensions.json`). Настройки сборки уже в
`.vscode/settings.json`: файл собирается при сохранении или по `Ctrl+Alt+B`,
PDF появляется рядом с `.tex`, временные файлы уходят в `build/`.

**Командная строка:**

```sh
cd lec
latexmk -pdf -aux-directory=build angem.tex
```

Ответы собираются так же, только из папки `kollokvium`.

## Новый предмет

Создать `lec/<предмет>.tex` с такими первыми строками:

```latex
\documentclass[a4paper, 12pt]{article}
\input{preamble.tex}
```

Потом собрать, закоммитить `.tex` вместе с `.pdf` и добавить строку в таблицу «Лекции».
Имя файла — латиницей, без пробелов и скобок, иначе ссылки в README ломаются.
