# Конспекты лекций

Конспекты лекций в LaTeX. Готовые PDF лежат в папке `lec/` рядом с исходниками,
GitHub открывает их прямо в браузере.

| Предмет | Файлы | Темы |
|---------|-------|------|
| Аналитическая геометрия | [PDF](lec/angem.pdf)&nbsp;·&nbsp;[tex](lec/angem.tex) | матрицы и определители, обратная матрица, СЛАУ и метод Гаусса, собственные значения и векторы, комплексные числа, векторы и базис |
| Математический анализ | [PDF](lec/matan.pdf)&nbsp;·&nbsp;[tex](lec/matan.tex) | множества, алгебра высказываний, предел последовательности, предел функции, замечательные пределы, сравнение бесконечно малых |
| Программирование | [PDF](lec/Proga.pdf)&nbsp;·&nbsp;[tex](lec/Proga.tex) | арифметические выражения, схемы алгоритмов, подпрограммы, ветвление, циклы, списки, матрицы, кортежи |
| Теоретическая информатика | [PDF](lec/TF.pdf)&nbsp;·&nbsp;[tex](lec/TF.tex) | информация и данные, система передачи информации, дискретные и непрерывные каналы, дискретизация |

Подробное оглавление — в начале каждого PDF.

## Структура

```text
lec/
├── angem.tex      аналитическая геометрия (преамбула внутри файла)
├── matan.tex      математический анализ
├── Proga.tex      программирование (преамбула внутри файла)
├── TF.tex         теоретическая информатика
├── preamble.tex   общая преамбула для matan и TF
├── *.pdf          собранные конспекты
└── build/         временные файлы сборки, в git не попадают
```

Один предмет — один файл. Новая лекция дописывается в конец файла своего предмета.

## Сборка

Нужен MiKTeX или TeX Live с `latexmk`. В MiKTeX нет Perl, без которого `latexmk`
не запускается, — его ставят отдельно, например [Strawberry Perl](https://strawberryperl.com/).
Компилятор — pdfLaTeX.

**VS Code.** Нужно расширение LaTeX Workshop (VS Code предложит его сам,
список лежит в `.vscode/extensions.json`). Настройки сборки уже в
`.vscode/settings.json`: файл собирается при сохранении или по `Ctrl+Alt+B`,
PDF появляется рядом с `.tex`, временные файлы уходят в `lec/build/`.

**Командная строка:**

```sh
cd lec
latexmk -pdf -aux-directory=build angem.tex
```

## Новый предмет

Создать `lec/<предмет>.tex` с такими первыми строками:

```latex
\documentclass[a4paper, 12pt]{article}
\input{preamble.tex}
```

Потом собрать, закоммитить `.tex` вместе с `.pdf` и добавить строку в таблицу выше.
